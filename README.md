# aitd-marconi

Pasaje a Web del Alone in the Dark — Marconi Version. Incluye el proyecto original de 2014–2015 y su port web iniciado en 2026.

- [Jugar en el navegador](https://facundoraulbistolfi.github.io/aitd-marconi/Web/)
- [Descargar la versión Delphi para Windows](https://facundoraulbistolfi.github.io/aitd-marconi/Alone%20in%20the%20Dark%20-%20Marconi%20Version/AITDMV.exe)
- [Ver el proyecto Delphi y sus fuentes](./Proyecto/Alone%20in%20the%20Dark%20-%20Marconi%20Version/)

El port web es estático y no necesita instalación. GitHub Actions publica automáticamente `Web/` junto con los recursos que necesita.

La banda sonora no forma parte de esta distribución pública porque el material del proyecto no incluye permisos de redistribución. El port oculta sus controles cuando detecta que las pistas no están disponibles. La versión original para Windows también se publica sin esos archivos de audio.

El proyecto Delphi usa TGIFImage. La fuente modificada de esa dependencia no se redistribuye aquí; para recompilar se necesita obtener una versión compatible de su [autor](https://melander.dk/delphi/gifimage/) y respetar sus condiciones. Se conserva el ejecutable original.

Los derechos de cada parte del proyecto permanecen con sus respectivos autores. Este repositorio no agrega una licencia abierta para el material original.
